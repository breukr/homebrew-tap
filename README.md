# Breukr Homebrew tap

Homebrew casks for apps by Breukr.

## Shotbolt

Screenshots and recordings for Mac: [shotbolt.app](https://shotbolt.app).

```sh
brew install --cask breukr/tap/shotbolt
```

Shotbolt updates itself (Settings → Advanced → About Shotbolt, or the update panel), so `brew upgrade` skips it unless you
pass `--greedy`. The cask is bumped with every release.

Requires macOS 26 or later, Apple silicon or Intel.
